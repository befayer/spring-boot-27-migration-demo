# Промпт для Kodacode

Переведи этот сервис со Spring Boot 2.7 на Spring Boot 3.5.

Сначала прочитай `AGENTS.md` и `docs/MIGRATION.md`, затем изучи код и контрактные тесты в `src/contractTest`.

Порядок работы:

1. Запусти `scripts/contract-check.sh` на текущей версии и зафиксируй исходный результат.
2. Составь план миграции и перечисли риски.
3. Выполни миграцию.
4. Запусти `./gw build` и `scripts/contract-check.sh`.
5. Если контрактные тесты падают, найди причину и исправь код приложения. Тесты и их ожидания не меняй.
6. Повторяй, пока все критерии приёмки из `docs/MIGRATION.md` не выполнены.

В конце дай отчёт в формате из `docs/MIGRATION.md`.
